Canvas Mode: editing something that moves

An animated section has three editable layers, and they need three different kinds of control. Two of them are new. This is what they'd look like — the panels below are working, so drag things.

The three layers

Marthe's journey is one experience made of parts that change at different rates. Her words change often. Her tuning changes occasionally. The code that makes a particle field respond to scroll doesn't change at all — and shouldn't be exposed as if it did.

Content · editable today

Words, images, stops

Already data in her chakraSections.ts. Reorder, rewrite, add a stop.

Parameters · new

Density, tempo, hue, scale

Numbers the code already reads, exposed as controls that can't be set to nonsense.

Choreography · new

What drives what

Scroll drives progress; progress drives the canvas. Wiring is editable, the maths is not.

Parameters

The inspector is the familiar half. Each control is declared by the component itself — name, type, range — so the editor renders something that physically cannot produce a broken frame. The preview is the real component, running.

Choreography

This is the part nothing today can do. An experience isn't a list of blocks — it's a set of relationships. Scroll position becomes a progress value; progress moves the particle field, the orb's scale, and which stop is showing. Editing that means editing the wires, never the maths.

So the surface is two things: a list of driver → target links, and a scrubber that lets you play the relationship without scrolling a real page. Drag the scrubber.

What's genuinely new

Two of the three layers already have machinery. Naming which is which keeps the proposal honest.

PieceExists todayTo build
Declared editable surface AtomSpec — atoms already declare their controls, with a CSS emitter and draft/publish from the DB The same idea one level up, on a section
Live preview + publish The Sandbox does this now, without a deploy Nothing
Composite section rf-accordion, rf-steps — one block owning an ordered internal list The same shape, with a canvas inside
Per-site tokens One site-scoped override (siteBackground) Generalise to colours, fonts, scale
Driver → target wiring — All of it
Scrubbing — All of it

One decision hides in here. A scrubber only works if progress is a value the section owns, rather than something read live from the window. That's a small change to how her journey computes its own position — and it's what makes the thing testable, previewable, and reduced-motion-safe in one move.
