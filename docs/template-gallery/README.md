# Template gallery — reference set

Source material for building out the TGV Office template gallery.

- `reference-categories.json` — the 44 industry + 6 platform categories scraped from https://www.sitebuilderreport.com/templates/ (2026-11-18, 2,156 unique templates).
- `reference-picks.json` — the 120 templates Gio picked to emulate (name, platform, live preview URL, full screenshot URL, category slugs).
- Picker artifact (re-pick there, then re-export): https://claude.ai/artifact/1JdZzxKbwbtJoVccE2hc4T — picks live in its db doc `picks/state`.
